Strategy & Recommendations

ข้อเสนอแนะที่สร้างจากข้อมูลที่เลือกอยู่

ข้อมูลที่ควรเก็บเพิ่ม

เพื่อให้ตัดสินใจได้แม่นยำขึ้น

1. ต้นทุนบริการและต้นทุนสินค้า เพื่อวัดกำไรขั้นต้น
2. วันนัดครั้งถัดไปและวันที่ควรกลับมา เพื่อวัดการกลับมาซ้ำ
3. แหล่งที่มาของ lead และแคมเปญ
4. จำนวน lead / booking / no-show / conversion
5. สถานะคอร์สและยอดคงเหลือของแต่ละลูกค้า
6. เป้าหมายยอดขายรายเดือนและ capacity ของคลินิก

ข้อควรระวังในการตีความ

• แถวที่ยอดสุทธิเป็น 0 อาจเป็นการใช้คอร์สเดิม ของแถม หรือข้อมูลที่ยังไม่สมบูรณ์ ไม่ควรนับเป็นยอดขายที่หายไปทันที
• ชื่อลูกค้าและ HN อาจสะกดต่างกัน จึงควรใช้ HN เป็นหลักเมื่อมีข้อมูล
• เดือนที่ยังไม่มีข้อมูลจริงจะไม่ถูกตีความว่าเป็นยอดขายศูนย์ทางธุรกิจ
• Dashboard นี้เป็นเครื่องมือช่วยวิเคราะห์ ไม่ใช่ระบบเวชระเบียน

เชื่อมต่อ Google Sheets

ใช้ Google Apps Script เป็น API เพื่ออ่าน/เพิ่ม/แก้ไข/ลบข้อมูล

สถานะปัจจุบัน: Dashboard ทำงานแบบ local-first และบันทึกในเบราว์เซอร์ก่อน การเชื่อม Google Sheets จะเริ่มทำงานหลังใส่ Web App URL ที่ Deploy แล้วเท่านั้น
ขั้นตอนตั้งค่า
1. สร้าง Google Spreadsheet ใหม่ แล้วตั้งชื่อชีตแรกว่า Sales
2. เปิด Extensions → Apps Script แล้ววางโค้ดตัวอย่างด้านล่าง
3. Deploy → New deployment → Web app; Execute as: Me; Who has access: Anyone (หรือจำกัดสิทธิ์ตามนโยบายองค์กร)
4. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางด้านบน
5. ทดสอบการเชื่อมต่อก่อนใช้งานจริง

Google Apps Script — ตัวอย่าง API

รองรับ GET อ่านข้อมูล และ POST เขียนข้อมูลทั้งชุด

ข้อจำกัด: การเขียนข้อมูลแบบ CRUD ตรง Google Sheets จากเว็บที่เปิดในเบราว์เซอร์มีข้อจำกัด CORS/การยืนยันตัวตน และตัวอย่างนี้ส่งข้อมูลเป็น JSONP-compatible GET/POST แบบพื้นฐาน การใช้งานจริงที่มีข้อมูลลูกค้าควรเพิ่ม authentication, จำกัดสิทธิ์ และไม่เปิดชีตข้อมูลส่วนบุคคลเป็นสาธารณะ
